Sorting Algorithm Playground

手動練習排序、遞迴拆分與合併，以及 Quick Sort 指標追蹤。

資料設定

輸入 2–12 個數字，可使用 5A、5B 等標記觀察穩定性。 比較時以數字部分為準。

Normal Mode

點擊兩個數字可以交換位置；拖曳數字到另一個數字， 則會插入該位置，其餘元素依序移動。

Insertion Sort — Key Storage

先取出 Key，接著點擊空位左邊的元素使它向右移動， 最後將 Key 插入空位。
